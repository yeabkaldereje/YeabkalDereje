# Yeabkal Dereje — Portfolio

Portfolio of Yeabkal Dereje, a senior graphic and UI/UX designer based in Addis Ababa, Ethiopia.

**Live site:** https://yeabkal.is-a.dev

Hand-built with HTML, CSS and vanilla JavaScript. No frameworks, no build step. Hosted on GitHub Pages.

## Structure

- `index.html` — the page
- `assets/css` — styles
- `assets/js` — behaviour, content data and the Amharic/English switch
- `assets/img` — work (WebP thumbnails and lightbox versions), client logos, favicons and the sharing image
- `assets/Yeabkal_Dereje_CV.pdf` — CV
- `CNAME` — custom domain for GitHub Pages
